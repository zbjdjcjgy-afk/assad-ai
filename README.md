# ASSAD AI — Early Prototype

ASSAD AI is an early, mobile-friendly prototype for turning goals into starter action plans.

## Included
- Responsive landing page
- English, Arabic and French interface switching
- RTL layout for Arabic
- Local demo plan generator (no AI API connected yet)
- ASSAD CORE, AGENTS, WORKSPACE and CREATIVE feature preview

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Upload the project files to the root of your repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Important
This is a front-end prototype. It does not yet include user accounts, a database, payments, or a live AI model. Never put private API keys in browser JavaScript or a public repository.
